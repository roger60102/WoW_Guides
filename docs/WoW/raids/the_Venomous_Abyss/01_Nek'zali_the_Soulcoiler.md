## 1號首領: 『纏魂者』尼札利
![nekzalithesoucoiler](/images/nekzalithesoulcoiler.png)
最後編輯時間: 2026/08/25

## 簡介
分為P1、中場與P2，王的血量剩餘50%時轉階段，中場召喚的大怪擊殺完進入P2。
場中央為纏魂之井，每個小怪觸碰到井或玩家在井中死亡會使王獲得能量，若滿能量將施放滅團技。
整場戰鬥場邊會週期召喚數個小怪，小怪自帶護盾，護盾存在期間無仇恨並且只會朝井移動。
中場開始會先在場地一端召喚第一個大怪，擊殺後於另一端召喚第二個大怪，大怪的存在使王免疫且無法選中。
進入P2後王會週期性全場aoe並自動獲得能量。

## 指南
### 普通難度
- 小怪吃控場，需盡速擊殺避免小怪碰到井，小怪自帶的護盾只會受到魔法傷害，建議遠程優先轉火，護盾破除後坦克即可做仇恨。
- 王的近戰攻擊會疊加降療效果，打坦技會朝坦克方向發射數個靈魂，命中時的全場aoe會隨距離減少，因此坦克需移動到團隊另一側的場邊，保持路徑淨空並且同時換坦。
- P1王每次到場中央的井中，造成持續全場高額aoe時會獲得25點能量，因此P1也不能拖太久。
- 王會點數個人頭頂綠箭頭，被點名移動到場邊等待治療驅散魔法後，會原地刷新會緩慢移動的綠圈。
- 中場依序擊殺大怪，期間的點名大紅圈全員分攤即可，未分攤者會被施加dot。
- P2開始王能量歸零，2:30滿能量後狂暴。

### 英雄難度
- 每次小怪或玩家使王獲得能量時，造成的全場aoe與dot會疊加buff，1分鐘內使該傷害提升。
- 中場階段死亡的小怪，屍體會留存供後續原地復活，需利用大怪的點名大紅圈，與未分攤玩家的小紅圈將小怪屍體燒掉。
- 大怪的點名大紅圈需安排分攤人數，剩餘等中小紅圈再找屍體燒。

### 傳奇難度
- 中場期間井中內場會召喚一個特殊大怪，其存在會持續造成外場全場aoe，並將全員玩家吸引至場中央，同時井可安全觸碰進入。
- 內場也會持續全場aoe，離開後會被施加觸碰井和內場aoe的易傷。
- 特殊大怪需斷法否則即死，擊殺後中止外場aoe與吸引效果，此外觸碰場內移動的靈魂會施加dot。
- P2王施法使綠圈換位置時會中斷施法並沉默。

## 技能
### P1
- **纏魂之井**: 場中央的綠井，每個小怪觸碰會觸發**纏魂儀式**。
    - **纏魂**: 玩家在井中死亡同樣會觸發**纏魂儀式**。
    - **纏魂儀式**: 造成全場aoe並疊加dot，同時使王獲得5點能量。
    - **解纏憤怒**: 尼札利滿能量會施放，提升攻速與移速並大幅增傷，同時免疫嘲諷。
    ::: details 英雄難度
    每次觸發**纏魂儀式**時會疊加**儀式燃燒**。

    - **儀式燃燒**: 1分鐘內使**纏魂儀式**增傷。
    ::: 
- **纏魂點燃**: 尼札利回到井中觸發5次**纏魂儀式**，並刷新大量**痛苦回音**。
    - **痛苦回音**: 對命中範圍內造成傷害附帶擊退。
- **精華撕裂**: 點數名玩家頭頂綠箭頭，短暫吸引後造成傷害附帶擊退，同時施加dot。
dot效果移除時會召喚**潛伏的教徒**造成範圍aoe。
    - **潛伏的教徒**: 教徒自帶綠圈並緩慢繞場移動，綠圈內持續aoe並降低移速。
- **受擾的阿曼尼**  
場邊週期召喚的小怪，小怪自帶**墓縛進擊**。  
    - **墓縛進擊**: 25%生命值的魔法護盾，護盾存在期間不會死亡且只會朝**纏魂之井**移動。
    - **死屍荒疫**: 死亡時造成全場aoe並疊加dot。
    ::: details 英雄難度
    - **甦醒軀殼**: 中場階段小怪的屍體原地復活時，造成數次全場aoe。
    ::: 
- **附身彈幕**: 朝當前目標發射數個靈魂，命中路徑上玩家時造成全場aoe，傷害與距離成反比。
- **空洞打擊**: 近戰攻擊會疊加dot，期間降低受到治療與吸收效果。

### 中場
尼札利生命剩餘50%時撤回纏魂之井，依序召喚2個嘉薇的回音使其免於傷害。

- **嘉薇的回音**  
中場大怪，自帶**甦醒繫鏈**。
    - **甦醒繫鏈**: 使尼札利免疫傷害
    - **靈魂轉移**: 被召喚時引導，數秒後對直線型範圍內造成傷害。
    - **飢饞蛇火**: 點1名玩家套大紅圈，數秒後範圍內造成傷害，該傷害可分攤。
        - **滑溜烈焰**，未分攤者會受到傷害並施加dot。
        ::: details 英雄難度
        **滑溜烈焰**會套小紅圈，數秒後造成**火葬**。

        - **火葬**: 造成傷害並施加dot，同時可燒掉範圍內小怪屍體以及為小怪施加dot。
        ::: 
::: details 傳奇難度
- **攫取深淵**: 中場開始內場會召喚1個**沉溺回響**，其存在期間外場持續全場aoe並將全員向井中吸引，同時可安全觸碰井進入內場。
    - **不朽盤繞**使內場持續造成全場aoe。
        - **沉溺回響**  
        內場特殊大怪，會施放**纏魂者詛咒**。  
            - **纏魂者詛咒**: 使內場玩家被**纏魂**而死亡。
        - **旋動之魂**: 觸碰內場的靈魂會疊加dot。
    - **靈魂耗弱**: 離開內場會被施加debuff，使**不朽盤繞**與**纏魂儀式**易傷。
::: 
- **受擾的阿曼尼**  
場邊週期召喚的小怪，小怪自帶**墓縛進擊**。  
    - **墓縛進擊**: 25%生命值的魔法護盾，護盾存在期間不會死亡且只會朝**纏魂之井**移動。
    - **死屍荒疫**: 死亡時造成全場aoe並疊加dot。
    ::: details 英雄難度
    - **甦醒軀殼**: 中場階段小怪的屍體原地復活時，造成數次全場aoe。
    :::
