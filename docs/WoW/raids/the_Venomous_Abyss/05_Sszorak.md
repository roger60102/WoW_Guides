## 5號首領: 司佐拉
![sszorak](/images/sszorak.png)
最後編輯時間: 2026/09/07

## 簡介
純單體首領戰，場地為八角形，左右兩邊共6個空洞，每輪會有隨機3個空洞依序吹出強風使全場玩家被吹動，要出強風的空洞會有明顯順序提示，吹風期間王會定在原地並且易傷。
王會在開始吹風前點名頭頂綠箭頭放球，球在持續時間結束或玩家觸碰時造成全場aoe附帶擊退，並且賦予有效抵抗強風的效果。

此外王還會5連擊，其中包含向外噴發數個龍捲風1次、不可分傷扇形與可分傷扇形各2次，順序不定。

## 指南
### 普通難度
- 王會點數名玩家頭頂綠箭頭，需到吹風提示的另一端場邊放球，放球時造成的全場aoe與距離成反比。
- 吹風時需撞球，獲得附著效果，否則非常容易被吹下平臺。
- 2次不可分傷的扇形為白色，注意換坦1人吃1次。
- 2次可分傷的扇形為綠色，造成的傷害與後續dot皆可分攤，若人數太少會即死。
- 穿插在扇形連擊中的龍捲風會在場上移動持續一段時間。
- 王會點數名玩家套白圈，不久後會朝提示方向擊飛，被點名的人需要尋找和自身反向的人，擊飛後得以互相抵銷。
- 坦克注意王的近戰攻擊也會疊加物理易傷，需視情況換坦。
- 整場戰鬥會有環境aoe。

### 英雄難度
- 可分傷扇形後續的dot期間，會使下次受到的可分傷扇形易傷，因此需分隊分攤。
- 點數名玩家頭頂綠箭頭的同時，會刷新數個地板技並汙染地板，站在綠水上會易傷，綠水可被強風吹動。

### 傳奇難度
- 王會施放標記1名玩家套紅圈，開始持續獲得怒氣，當紅圈內達14人時消耗所有怒氣造成傷害，需在王怒氣快滿時進圈。
- 消耗所有怒氣造成傷害後，對範圍內所有玩家套四芒星，此時需盡速分散，數秒後噴發4道直線傷害，若被命中同樣會套四芒星。
- 滿怒氣後滅團，開場約33秒第1次，此後間隔50秒。

## 技能
- **凜風大漩渦**: 依序吹出3次不同方向的強風。
    - **站穩腳步**: **凜風大漩渦**期間，司佐拉會定原地並受到易傷。
::: details 傳奇難度
- **毒蛇之怒**: 點1名玩家套紅圈，期間司佐拉會持續獲得怒氣，當紅圈內達14人時會消耗所有怒氣施放**殺戮之途**，若成功滿怒氣會施放**無縛凶暴**。
    - **無縛凶暴**: 大幅增傷並提升攻速，持續至戰鬥結束。
    - **殺戮之途**: 衝鋒紅圈目標，造成範圍aoe，並施加**惡疾**。
        - **惡疾**: 被**殺戮之途**命中的所有玩家套四芒星並施加dot，結束後噴發4道直線傷害，命中會施加**惡疾**。
::: 
- **至尊掠食者**: 由2次**摧殘**、2次**截肢**與1次**暴風**組成的連擊，施放期間受到嘲諷會立即更換當前目標。
    - **摧殘**: 當前目標方向的白色扇形地板技，數秒後造成高額傷害並疊加該技能易傷。
    - **截肢**: 當前目標方向的綠色扇形地板技，數秒後造成高額傷害同時施加**致殘劈砍**，該傷害可分攤，並且若命中人數太少會即死。
        - **致殘劈砍**: **截肢**後續的dot，該傷害依**截肢**命中人數分攤。
        ::: details 英雄難度
        **致殘劈砍**期間**截肢**易傷。
        ::: 
    - **暴風**: 司佐拉刷新數個龍捲風包圍自身，數秒後向外噴發，龍捲風會持續在場上移動一段時間，命中會造成傷害並疊加dot，期間降低移速，可被驅散中毒。
- **毒素湧流**: 點數名玩家頭頂綠箭頭並施加dot，結束後造成全場aoe，該傷害與距離成反比，同時原地刷新**黏稠囊腫**。
    - **黏稠囊腫**: 被點名綠箭頭所放的球，會存在一段時間，結束或有人觸碰會造成全場aoe附帶擊退並施加dot，期間移速降低並可更好的附著在場地上。
    ::: details 英雄難度
    - **腐蝕利爪**: 點名綠箭頭同時刷新數個地板技，會留下**腐蝕殘餘**。
        - **腐蝕殘餘**: 汙染地板範圍內持續造成aoe並施加易傷。
    ::: 
- **狂怒側風**: 點數名玩家套白圈，數秒後範圍內造成aoe並向指定方向擊飛，同時施加**動盪強風**。
    - **動盪強風**: 使掉落速度降低，與其他受**動盪強風**影響的人碰撞會互相抵銷。
- **腐蝕毒液**: 司佐拉的近戰攻擊會當前目標疊加物理易傷。
- **烏拉特克領域**: 持續造成全場aoe。
