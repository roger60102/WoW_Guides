## 2號首領: 埋葬衛哨
![entombedsentinels](/images/entombedsentinels.png)
最後編輯時間: 2026/08/31

## 簡介
由烏拉特克之息(綠魔像)與烏拉特克之血(紅魔像)組成，不共享生命值，並且相距40碼內兩者會減傷99%。
滿能量後轉階段，開場45秒第一次，此後間隔1:30。
轉階段持續30秒，期間兩個魔像減傷99%，並且生命值較低者會恢復至與較高者相同。
同時全員會被施加debuff，隨機分配1綠3紅、2綠2紅或3綠1紅的符號於頭頂顯示，30秒後造成高額傷害與dot。

## 指南
### 普通難度
- 團隊分成2組，兩隊的坦克分別拉1隻王到場地兩端，需盡可能修齊血量。
- 王快滿能量時建議全員提前分散，由於30秒內兩隻王皆處於減傷狀態，因此專心處理機制即可。
- 轉階段期間的debuff需於30秒內消除，需倆倆玩家一對消除，1綠3紅與3綠1紅互相碰撞，2綠2紅尋找相同者碰撞，全員debuff皆消除時可提早結束轉階段，若撞錯debuff會有變化，可能無法再消除。
- 兩隻王皆會對附近玩家疊加dot，轉完階段後需換邊，同時也是換坦。
- 綠魔像會召喚持續全場aoe的軟泥，需盡速轉火擊殺。
- 綠魔像會在場地上隨機位置刷新綠圈，需在爆炸前主動觸碰。
- 紅魔像施加的高額dot治療注意驅散。
- 紅魔像的點名大紅圈愈多人分攤，可減少後續dot層數。

### 英雄難度
- 綠魔像召喚的軟泥死亡以及觸碰綠圈皆會刷新綠球，數秒後射向綠魔像，對路徑上造成傷害，不論哪一隊都需注意躲避。
- 紅魔像的所有技能，包含中場撞錯的dot結束後會汙染地板，髒水大小與dot層數成正比。
- 紅魔像的高額dot可驅散規避汙染地板，大紅圈分攤結束後集中等放水，換王後坦克注意放水位置。

### 傳奇難度
- 週期點數名玩家套紅圈，該dot需和其他被套紅圈者互撞消除，同時避免碰到正常玩家。

## 技能
::: details 傳奇難度
- **『惡性之毒』伐許尼克**  
週期性出現在場中，無法攻擊並會施放**移轉原型毒液**干擾玩家。
    - **移轉原型毒液**: 點數名玩家套紅圈施加dot，與其他同為被施加者碰撞可無傷移除，若觸碰未被施加者則觸發**原型毒液爆發**。
        - **原型毒液爆發**: 範圍內造成高額傷害附帶擊退。
::: 
- **埋葬哨衛**  
由烏拉特克之息與烏拉特克之血組成。
    - **烏拉特克之威**: 兩個魔像相距40碼內皆會受到減傷99%。
    - **酸蝕印記**: 綠魔像週期性對周圍玩家疊加dot。
    - **血魄印記**: 紅魔像週期性對周圍玩家疊加dot。
- **烏拉特克之息**  
綠魔像。
    ::: details 英雄難度
    - **活體毒液**: 使自身技能會附帶刷新綠球，數秒後射向自身，對路徑上造成高額傷害。
    ::: 
    - **毒液凝結**  
    召喚出來的軟泥，自帶**汙染**。  
        - **汙染**: 持續造成全場aoe。
    - **毒素之滴**: 刷新大量綠圈，觸碰時造成傷害並摧毀。
        - **劇毒衝擊**: 未被摧毀的綠圈會在數秒後造成全場高額aoe。
    - **強化猛擊**: 對當前目標造成高額傷害，每次施放疊加物理增傷，直到命中不同目標後移除。
- **烏拉特克之血**  
紅魔像。
    ::: details 英雄難度
    - **鮮血之毒**: 使自身技能效果結束時汙染地板，層數與汙染範圍成正比。
    ::: 
    - **荒疫之血**: 點數名玩家施加高額dot。
    - **不穩定的瘴氣**: 點1名玩家套大紅圈，數秒後範圍內造成傷害並疊加**黏附黑暗**，傷害與**黏附黑暗**層數可分攤。
        - **黏附黑暗**: 對目標疊加dot。
    - **血毒注射**: 對當前目標造成高額傷害並疊加dot。
- **硫酸恆定**: 滿能量後兩個魔像回到場中央，30秒內減傷99%，並且生命值較高者會為較低者恢復至與自身同等血量。
    - **螺旋毒素**: 為幾乎全員施加dot，隨機分配3種標記，與其他玩家碰撞可疊加自身層數，若剛好4層可無傷移除。
        - **培育爆發**: 為碰撞或碰撞錯誤會時間結束後造成高額傷害與dot。
