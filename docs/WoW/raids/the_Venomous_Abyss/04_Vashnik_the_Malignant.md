## 4號首領: 『惡性​之​​毒』​伐許尼克
![vashnikthemalignant](/images/vashnikthemalignant.png)
最後編輯時間: 2026/09/07

## 簡介
場地上共3座不同屬性的噴泉，分別為鮮血(紅)、暗影(紫)與火焰(橘)。
王滿能量時會吸取距離最近的2座噴泉，額外獲得對應屬性技能並召喚軟泥，開場20秒第1次，此後間隔80秒。

噴泉每次被吸取，王會獲得2分鐘buff，使下次吸取該噴泉時造成的傷害，以及從該噴泉召喚出來的軟泥生命值疊加。
所有軟泥無仇恨並且只會向場中央的毒坑移動，若成功抵達會造成全場高額aoe並施加dot。

## 指南
### 普通難度
- 正常打法為每次吸取噴泉且處理掉軟泥後，帶著王順時針或逆時針往下個場地移動，避免王疊加太多同屬增傷。
- 除了第一次吸取外，每次必定有一座噴泉會強化，避免軟泥走到場中央毒坑的同時，建議強化軟泥優先擊殺。
- 整場戰鬥會有環境aoe，每次吸取不同噴泉時會造成全場aoe外，也會疊加環境aoe傷害。
- 打坦技會造成高額傷害附帶dot，並且會疊加物理易傷，視情況換坦。
- 王的常規技能會點數名玩家套四芒星，被點名離開人群，數秒後噴發4個毒波。
- 王吸取紅噴泉後會點數名玩家套治療吸收盾與紅圈，需找人群集中站，期間唯有紅圈對其他玩家造成傷害時，能為被點名的人回血。
- 紅軟泥每次1隻，會分裂2次，並且在第一次分裂前免疫控場。
- 王吸取紫噴泉後會點數名玩家套治療吸收盾，期間刷新數個地板技。
- 紫軟泥每次數隻，自帶吸收盾，且死亡時會刷新大量地板技。
- 王吸取橘噴泉後會點數名玩家頭頂黃箭頭，被點名出人群，治療驅散後會造成全場aoe，傷害與距離成反比。
- 橘軟泥每次2隻，會持續造成全場aoe，並且死亡時還會額外造成一次全場高額aoe，盡量錯開時間擊殺，此外若存活太久會免疫控場並增加移速。

### 英雄難度
- 橘軟泥死亡時的爆炸會額外疊加dot。
- 場地週期刷新數個綠圈，需接圈否則造成全場aoe。

### 傳奇難度
- 每次吸取噴泉時會召喚數個無法攻擊的圖騰，施法成功造成高額aoe與疊加dot。
- 需利用四芒星噴發的毒波摧毀圖騰。
- 被點名紅圈的人，會被額外施加紅圈aoe易傷，因此不得與其他紅圈重疊。
- 被點名頭頂黃箭頭的人，會週期疊加dot。

## 技能
- **暢飲**: 伐許尼克吸取距離自身最近的2座噴泉，獲得對應技能、全場aoe與召喚軟泥，同時疊加1層**有毒蒸氣**。
    ::: details 傳奇難度
    - **惡意圖騰**  
    吸取噴泉時召喚的數個圖騰。
        - **惡意**: 施法成功造成全場高額aoe與疊加dot。
    ::: 
    - **鮮血噴泉**
        - **血能灌注**: 疊加**血液爆發**增傷，與**凝固毒液**的生命值。
        - **血液爆發**: 吸取**鮮血噴泉**造成全場aoe。
        - **凝固毒液**  
        紅噴泉召喚出來的1個紅軟泥。
            - **血紅堅韌**: 在第一次分裂前免疫控場效果。
            - **分裂凝塊**: 分裂出2個小型**凝固毒液**，最多2次。
    - **暗影噴泉**
        - **闇能灌注**: 疊加**幽暗爆發**增傷，與**劇毒之罩**的生命值。
        - **幽暗爆發**: 吸取**暗影噴泉**造成全場aoe。
        - **劇毒之罩**  
        紫噴泉召喚出來的數個紫軟泥。
            - **瘴氣塗層**: **劇毒之罩**自帶的傷害吸收盾。
            - **晦影爆發**: 死亡時會刷新大量地板技。
    - **火焰噴泉**
        - **烈焰灌注**: 疊加**引燃爆發**增傷，與**燃燒毒液**的生命值。
        - **引燃爆發**: 吸取**火焰噴泉**造成全場aoe。
        - **燃燒毒液**  
        橘噴泉召喚出來的2個橘軟泥。
            - **燃燒守護**: 持續造成全場aoe。
            - **腐蝕高漲**: 死亡時造成全場aoe。
            ::: details 英雄難度
            **腐蝕高漲**會額外疊加dot。
            ::: 
            - **硬化毒液**: 存活太久會免疫控場並提升移速。
    - **有毒蒸氣**: 持續造成全場aoe。
    - **惡意爆發**: 任何軟泥抵達場中央的毒坑後會造成全場高額aoe與疊加dot。
::: details 英雄難度
- **惡意催化**: 造成全場aoe並觸發**催化膽汁**。
    - **催化膽汁**: 刷新數個綠圈，對範圍內造成傷害，若範圍內無玩家則造成全場aoe。
::: 
- **瘟疫泡沫**: 點數名玩家套四芒星，不久後噴發4個**瘟疫波**。
    - **瘟疫波**: 命中造成傷害。
    ::: details 傳奇難度
    **瘟疫波**可摧毀**惡意圖騰**。
    ::: 
- **滴毒尖牙**: 對當前目標造成高額傷害並施加dot，同時疊加物理易傷。
- **適應感染**: 吸取對應噴泉後獲得特殊技能影響多名玩家。
    - **吸取感染**: 點數名玩家施加治療吸收盾，並且只能靠**虹吸血液**獲得生命值。
        - **虹吸血液**: 為被點名**吸取感染**的人套紅圈，範圍內持續aoe。
        ::: details 傳奇難度
        - **稀薄血液**: 被點名**吸取感染**的人會被額外施加**虹吸血液**易傷。
        ::: 
    - **冥魄感染**: 對多名玩家施加治療吸收盾，期間持續觸發**冥魄爆發**。
        - **冥魄爆發**: 治療吸收盾存在時，週期刷新數個地板技。
    - **爆發感染**: 點數名玩家頭頂黃箭頭，驅散時造成**腐蝕爆炸**。
        ::: details 傳奇難度
        **爆發感染**會額外疊加dot。
        ::: 
        - **腐蝕爆炸**: 造成全場高額aoe，該傷害與距離成反比。
