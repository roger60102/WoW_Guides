# 12.1(S2)M+: 盲目谷地
![theblindingvale](/images/theblindingvale.jpg)

- 12.0的五人本，位於哈朗達(座標: 27.8, 77.9)。
- 一王前有個平台上的花可由聖騎士或德魯伊互動，獲得5%加速與20%移速。
- 開頭目前主流會選走左邊打一王再過橋打二王。

## 一號首領: 光綻三人組
梅提克會刷新3個**肥沃壤土**，接著雷席克會依序對這3個位置**播光者突進**播種，最後由科基特引導**光綻射線**生成聖光花。3人共享生命值。

- 科基特的**光芒箭**必斷，點1人造成直傷。
- 雷席克會點1人**荊棘之刃**套大綠圈，數秒後閃現至目標身後施加流血，並於綠圈範圍內持續aoe。
- 梅提克的**岩床猛擊**為打坦技，坦克需覆蓋減傷，同時全員施加dot。
該技能刷新**肥沃壤土**。
- 科基特施放**光綻射線**時需1人站1個壤土，雖然期間會有dot，但可避免聖光花成功生長造成持續aoe。
成功阻止會留下髒水。

## 二號首領: 『聖光獵人』伊庫茲
**血棘之根**困住全員，並在滿能量時施放**嗜血凝視**追人，被追到會被吞掉**咬碎**，造成高額傷害持續3秒。

- **翠綠踐踏**造成全場aoe附帶擊退，同時全員套圈，數秒後刷新**血棘之根**，定身期間有dot，可使用解除定身技能或直接打掉。
- **喚棘者怒吼**造成6秒全場aoe，並刷新大量觸碰會生成**血棘之根**的髒水。
- 10秒的**嗜血凝視**期間除了不得被追到外，也要盡量引導伊庫茲摧毀路上的髒水。
- 生命值剩餘50%時觸發**光狂之亂**，伊庫茲獲得20%移速，並且每2秒全場aoe。

## 三號首領: 護光者魯亞
會在梟獸與熊型態間切換施放對應技能，生命值剩餘40%時切回人形態施放**谷之魂靈**，持續召喚分身施放所有技能。

- **看守者之怒**必斷，點1人造成直傷。
- 點3人**光火**施加dot，數秒後向外噴發6個龍捲風，不得重合站位需分散放風。
- **光落**刷新大量地板。
- 熊型態近戰攻擊提升100%，坦克須注意減傷。
- **兇殘痛擊**全員施加dot，血量刷滿可自動移除。
- 點3人依序施放**粉碎打擊**，目標方向的錐形震懾波，會施加100%該技能的易傷，需分散站位。
- **谷之魂靈**觸發後，會依序以**光火**、**光落**、**粉碎打擊**與**兇殘痛擊**為循環，直至戰鬥結束。

## 四號首領: 齊克特
**喚醒光綻**刷新以及喚醒場上休眠的小怪，打坦技**集中光束**可摧毀路徑上的休眠小怪。

- 進戰鬥後就會有環境aoe。
- **喚醒光綻**會刷新6個小怪並喚醒場上的休眠小怪，小怪只會點1人**光孢射擊**造成直傷，多斷法和給控場並盡速擊殺，使其進入休眠。
若有休眠小怪被喚醒會免疫打斷與控場，並獲得30%加速與增傷。
- **光綻精華**在場邊刷新數個逐漸飛向齊克特的光球，成功抵達會獲得護盾並增傷10%。
每人皆需吃2到3顆避免王碰到，吃球可疊加10%增傷與增療，但同時也有dot。
- 打坦技**棘刺**造成高額傷害附帶擊退與施加dot，坦克需注意減傷。
- 打坦技**集中光束**朝當目標方向發射射線，坦克需對準休眠小怪群，成功摧毀會留下髒水。
