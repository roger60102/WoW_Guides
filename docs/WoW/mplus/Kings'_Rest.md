# 12.1(S2)M+: 諸王之眠
![kingsrest](/images/kingsrest.jpg)

- 8.0的五人本，位於贊達拉-祖達薩(座標: 42.4, 58.3)。
- 一王後的四波怪喚醒順序不一定。

## 一號首領: 黃金風蛇
點2人**液態黃金**套圈，數秒後造成傷害並留下髒水。**財富的呼喚**會將髒水喚醒成小怪，小怪無仇恨只會朝黃金風蛇移動，若成功抵達黃金風蛇會獲得10%生命值護盾與增傷25%。

- 被套圈靠場邊集中放水。
- 打坦技**尾巴痛擊**，坦克注意減傷。
- **風蛇勁風**持續造成全場高額aoe附帶擊退，注意減傷。
- 戰鬥時間愈久小怪愈多，小怪喚醒時優先轉火給控場。

## 二號首領: 『墓葬者』瑪欽巴
點1人**吸取體液**施加dot，結束後獲得降低50%造成傷害與移速。點1人**入殮**關進場邊棺材內，成功救出期間瑪欽巴會依序打開其餘棺材召喚小怪。

- 點1人**燃燒腐化**套紅圈，數秒後範圍內aoe並留下髒水，需出人群到場邊放水。
- **入殮**時優先救人，否則會刷新太多全員施加dot的木乃伊小怪。
- **吸取體液**期間全員位置會刷新多次地板技，dot後續的debuff需生命值達90%以上自動移除。

## 三號首領: 部族議會
固定以『屠殺者』庫拉、『征服者』阿卡亞莉、『智者』薩納瑟爾為依序上場。
屠殺者的**迴旋戰斧**以及征服者的**一穿而過**，即便戰敗後仍會持續施放。

- 屠殺者會原地刷新地板技，數秒後造成範圍內aoe並向外扔出2個**迴旋戰斧**，持續在場地內向外旋轉，觸碰會擊退並附帶高額dot。
以及**斬首之斧**點1人施加流血，需注意減傷。
- 征服者的打坦技**至衰反手**，高額傷害附帶擊退，坦克需同時注意減傷與擊退方向。
以及點1人**一穿而過**套圈，需幫忙分攤。
- 智者對坦克施放**弧狀閃電**會額外彈跳至最多2人身上，需注意減傷。
以及**劇毒新星**必斷，否則對全員施加12秒dot。
- 智者施放**元素呼喚**召喚爆裂、洪流與雷擊圖騰，爆裂圖騰會造成全場超高額aoe，雷擊圖騰會沉默全員，洪流圖騰會刷新數個地板技。
按照爆裂、雷擊最後洪流的順序轉火。

## 四號首領: 達薩，開國神王
達薩與他的坐騎特札拉共享生命值。生命值高於80%時會召喚瑞邦，而生命值剩餘80%時，達薩會騎上特札拉，增加額外打坦技與點名地板技。

- 瑞邦會點1人**獵殺躍擊**，跳擊施加流血後持續頭前錐形震懾波。
以及**死亡咆哮**必斷，則造成全場aoe並恐懼。
- 達薩會點2人**空中潰擊**套紅圈，數秒後依序跳擊造成範圍內aoe。
騎上坐騎後會變點4人。
- 達薩的打坦技**劍刃連擊**，造成多斷高額傷害，坦克注意減傷。
- 達薩會施放**金輝毀滅**，造成全場高額aoe附帶dot，同時刷新大量地板技，並且自身獲得近戰攻擊額外造成火焰傷害與順劈效果。
注意減傷並且別和坦克一起站。
- 特札拉的打坦技**野蠻槌擊**，造成高額傷害並施加10秒流血附帶10%易傷，坦克注意減傷。
- 戰鬥期間場地上會週期刷新**穿刺之矛**地板技。

## 小怪
**祖爾之僕**: 可群體進攻驅散或免疫技能。
- 觸碰造成恐懼。

**活化的守護者**: 激怒時坦克注意減傷。
- 點1人方向**鎮壓猛擊**，頭前錐形震懾波，造成高額傷害附帶昏迷2.5秒。
- 激怒自身提升50%移速與75%攻速。

**影裔勇士**: aoe注意減傷。可驅散狂怒。
- **暗影旋風**造成全場aoe，同時刷新數個地板技。
- **戒備防禦**向前方架盾，免疫來自正面的攻擊。
- 激怒自身提升150%物理傷害。

**復生妖術師**: **暗霜箭**選斷。**妖術箭雨**必斷，漏斷後的dot可驅散詛咒。
- 點1人**暗霜箭**造成直傷。
- **妖術箭雨**造成全場高額aoe，並施加12秒dot。

**拉胡艾國王**: **叉狀閃電**注意減傷。
- 點1人**叉狀閃電**，造成直傷並額外彈跳至最多2人身上。
- **超載刷新**10碼地板技。

**瑪巴拉總管**: **穢邪癒合**必斷。
- 為1名盟友施放**穢邪癒合**，10秒內每2秒回7%生命值。

**守衛隊長阿圖**: **隊長之壁壘**給控場或驅散魔法。
- **隊長之壁壘**使周圍盟友減傷30%。

**提瑪吉國王**: 被套圈出人群。被追需風箏。
- 點1人**爆裂猛擊**套圈，數秒後範圍內aoe。
- 點1人**劍刃風暴**，近戰範圍持續旋風斬同時追人。

**瓦希皇后**: **靈魂之箭**選斷。**束縛靈魂**必斷或驅散魔法。

- 點1人**束縛靈魂**心控10秒。

**阿庫爾國王**: 優先擊殺。坦克注意減傷。
- 打坦技**致死流血**，造成高額傷害並施加流血。
- **吸取血液**持續造成全場aoe並為自身恢復同等生命值。

**血誓刺客**: 流血優先點名為被施加的人，注意減傷。
- 點1人施加流血。

**帕特拉皇后**: 可驅散狂怒。
- 引導**暗影箭雨**，全員位置刷新會留下髒水的地板技，。
- **野性狂暴**激怒自身與周圍盟友，15秒內提升25%攻速與施法速度。

**骷髏狩獵迅猛龍**: 可驅散狂怒。
