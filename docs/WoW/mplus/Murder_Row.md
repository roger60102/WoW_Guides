# 12.1(S2)M+: 兇殺路
![murderrow](/images/murderrow.jpg)

- 12.0的五人本，位於銀月城(座標: 56.2, 61.1)。
- 一王需和4個NPC對話才能解鎖，分別在4個房子裡。
- 一王前的房子裡生成共計3個惡魔違禁品，可和屋外的商人交易特殊道具。
- 道具有4種，每個道具只能交易1次，最推薦上膛的手槍在1王轉階段時使用。
- 魔化龍鰻蛋使自身30秒內提升15%加速。
- 擰心毒藥可使用3次，會讓目標生命值降低30%上限並昏迷6秒，但對首領和91級以上目標無效。
- 上膛的手槍可為路徑上目標施加16秒流血，期間易傷20%。
- 魔石召喚100碼內其餘隊友，並且15秒內提升50%移速。
- 一王後的偽裝身分隨機，表演者需接圈、清潔員需碰髒水、保全需把喧嘩的顧客踢出門口、服務生需依顧客指定端對應食物飲品。
達成五星評價可獲得5分鐘提升加速。

## 一號首領: 克絲提雅．法心
克絲提雅自帶**魔盾**減傷80%，並用**禁忌灌注**心控龍鰻尼波斯。當尼波斯生命值剩餘20%時可打破控制，反手施放**聖光注入**驅散魔盾，使克絲提雅20秒內昏迷，期間易傷115%並持續造成全場aoe。

- 克絲提雅的打坦技**混沌彈幕**，高額傷害並會彈跳至其他人身上。
- 尼波斯會**魔化噴霧**，頭前吐息並旋轉。
- 克絲提雅點1人**魔化新星**，閃現後原地刷新地板技。
- 克絲提雅會施放**鏡像**，召喚數個分身施法必斷或給控場，否則造成全場aoe，1人至少斷1個。

## 二號首領: 贊恩．刃悲
場地上會週期刷新數個**禁忌運輸**木桶，其中含有1、2個**灌魔貨物**會持續造成全場aoe。贊恩施放**連環謀殺**與全員連線，數秒後造成秒殺傷害。

- **狂舞殘殺**持續造成全場aoe，注意減傷。
- 打坦技**毒化**，高額傷害並施加中毒，期間降低30%生命值上限，需驅散中毒。
- 點2人**火焰彈**套圈，6秒後造成範圍內aoe並摧毀木桶，需炸掉綠桶留正常木桶。
- **連環謀殺**時需躲在正常木桶後規避傷害，木桶爆炸時會有地板技。

## 三號首領: 『殲滅者』薩索克斯
滿能量施放**惡魔之怒**，造成全場高額aoe並獲得buff，15秒內增傷30%及提升75%攻速，期間不斷原地留下髒水。

- 打坦技**軍團打擊**，頭前錐形震懾波，高額傷害附帶降低80%受到治療效果，坦克需往場外引技能。
- 點1人**投擲利斧**，斧頭存在期間持續全場高額aoe，傷害會疊加，需盡速轉火。
- **煉獄潰擊**全員套圈，數秒後範圍內aoe，需分散站位。
- **惡魔之怒**期間坦克需沿場邊慢慢帶位，因為髒水會擴散至一定大小。

## 四號首領: 莉希爾．燼怒
莉希爾會**古爾丹之指**全員套圈，數秒後範圍內aoe並刷新數個小怪。
接著召喚**惡魔之門**拉開距離並施放**惡毒浪潮**，若逐漸向外擴散的火焰波命中玩家，會疊加1分鐘dot，期間火焰易傷50%。
若命中惡魔小怪會強化，提升加速100%。

- 煉獄火會持續追坦克，綠圈內持續高額aoe，開場將莉希爾拉離煉獄火，後續稍微引開帶位即可。
- 點1人**混沌箭**造成直傷，必斷。
- **召喚邪惡犬魔**，近戰攻擊附帶暗影傷害，坦克注意減傷並優先轉火。
- 全員套圈時稍微分散即可，方便集火小怪。
- 莉希爾拉開距離施放**惡毒浪潮**期間減傷50%，需在火焰波接近前擊殺所有小怪，否則小怪強化。
- 火焰波可透過莉希爾的**惡魔之門**安全越過，使用後有1分鐘CD。
