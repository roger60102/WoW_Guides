# 12.1(S2)M+: 虛無之痕競技場
![voidscararena](/images/voidscararena.jpg)

- 12.0的五人本，位於虛無風暴(座標: 35.3, 65.3)。
- 開頭目前主流走右邊，因為右邊的大怪比較好處理。
- 一王打完上階梯後主流走右邊。
- 二王後需擊殺3個大怪吞噬殘暴者才能解鎖尾王。

## 一號首領: 塔茲拉
召喚5個影子，依次施放**虛空突進**1人被1個影子點名數秒後衝鋒，於終點位置刷新髒水。
**黑暗綻放**造成全場高額aoe，並且會使髒水向外噴發數個黑球。

- 坦克帶至場邊，**虛空突進**時遠程四散，近戰左右錯開，結束後帶位。
- 打坦技**虛無衝擊**，造成高額傷害附帶擊退，坦克注意減傷。
- **黑暗綻放**時注意減傷，場上髒水愈多，噴發出的黑球愈多。

## 二號首領: 奧托薩斯
點1人方向施放**劇毒之息**。
**毒液噴濺**造成全場aoe並刷新大量髒水，觸碰造成高額傷害並降低30%移速。
**駭人巨吼**造成全場高額aoe並從左右其中之一的毒池召喚小怪追坦克。

- aoe注意減傷。
- 打坦技**怪力爪擊**，造成高額傷害並施加中毒，可驅散中毒。
- 小怪存在期間每0.5秒全場aoe，移動路徑上會留下髒水，若坦克被追到會施加5分鐘自然易傷50%，優先轉火小怪。

## 三號首領: 查洛納斯
刷新3個**不穩定的奇異點**持續吸引全員。並點3人刷新**重力球**追人。

- 刷新**不穩定的奇異點**時站在三者中心可平均吸力，奇異點會持續全場aoe，觸碰會平靜15秒。
- **宇宙撞擊**全員套圈，數秒後圈內範圍aoe並施加dot，需分散站位。
- **重力球**存在期間每秒會為目標疊加dot與降低移速，需引導球與奇異點互相摧毀。
- 打坦技**黑暗波**，錐形震懾波，坦克無法規避。
- 點1人**虛無傾瀉**，持續朝目標方向發射黑球，命中造成高額傷害附帶擊退，需持續移動躲避。

## 小怪
**被統御的鬥士**: 可驅散狂怒。**挫志怒吼**必斷。
- 激怒自身，4秒內提升20%攻速，並點名1人易傷5%。
- **挫志怒吼**降低周圍敵人傷害25%。

**迷路的塞斯拉克**: 綠圈優先點名遠程。
- 點1人位置刷新綠圈。

**被控制的薩滿**: **熔岩箭**選斷。優先轉火圖騰。
- 點1人**熔岩箭**造成直傷。
- 召喚**熔岩圖騰**每2秒對全員aoe。

**虛無之觸魔導師**: **暗影箭雨**必斷。被套圈出人群並注意減傷。
- **暗影箭雨**造成高額全場aoe。
- 點1人**空無爆發**套藍圈，數秒後圈內範圍高額aoe。

**『法颶』拉捷克斯**: **叉狀閃電**注意減傷。優先轉火球。aoe注意減傷。
- 點1人**叉狀閃電**造成直傷，並彈跳至額外最多2人身上。
- 召喚3個**崩解之球**，球會施法全場aoe並施加dot。
- **雷鳴風暴**持續造成全場aoe與刷新大量地板技。

**殘酷監督者**: 破盾打斷aoe與移除增傷。被追需風箏。
- **蠻擊**為自身套盾，護盾存在期間持續全場aoe，傷害會疊加。
- 點1人**錘暴**，近戰範圍持續旋風斬並追人。

**『不撓者』愛琪拉**: 優先轉火矛後分散。
- 點1人**兇猛躍擊**，跳向目標施加dot並接**裂地者**15碼地板技，會留下髒水。
- 插下**勇士之矛**將全員聚集在一定範圍內，並接**野蠻潰擊**全員套圈，數秒後範圍內aoe。

**奇提戈斯**: aoe注意減傷。
- 刷新2個會移動的蟲群，觸碰施加dot。
- **陰險光環**10秒內每2秒造成全場aoe。

**防護的烏龜**: 有盾時遠離，趁盾消失時盡速擊殺。
- 引導**龜殼守護**範圍內減傷75%，結束後暈眩15秒，期間易傷20%。

**布魯托克**: 建議帶位至場邊對牆衝鋒。
- 被動使其移動時會造成全場aoe。
- 打坦技**頭錘**，造成高額傷害附帶擊退，並接**潰擊衝鋒**朝目標方向蓄力衝鋒。

**被劫持的龍獸**: 
- 刷新數個地板技。

**諂媚的塔拉賽克**: debuff可魔法驅散。
- 打坦技降低目標10%護甲值。

**憤怒的葉殼蟲**: **猛烈狂沙**必斷。
- 引導**猛烈狂沙**持續全場aoe附帶降低移速。

**噬殺蟲尖嘯者**: **瘋狂尖叫**必斷。
- **瘋狂尖叫**恐懼全員。

**野蠻碎爪**: 坦克注意減傷。
- 打坦技施加10秒20%易傷。

**警戒的哈洛爾**: 被點白圈需分攤，分攤後離開白圈。被點藍圈出人群並注意減傷。
- 點1人**空中打擊**套大白圈數秒後跳擊對範圍內aoe，會留下數秒後爆炸的髒水。
- 點1人**虛無光束**套藍圈，持續圈內aoe，優先點遠程。

**吞噬殘暴者**: aoe注意減傷。優先轉火將被**吞噬**的小怪。
- **驚懼低吼**造成全場aoe附帶擊退，同時施加12秒dot。
- 打坦技**殘暴爪**，造成多段高額傷害。
- 對1個小怪施法8秒**吞噬**，成功後恢復50%生命值並增傷20%。

**虛無控制者**: **癒合虛無**必斷。
- **癒合虛無**為吞噬殘暴者每2秒恢復3%生命值。
