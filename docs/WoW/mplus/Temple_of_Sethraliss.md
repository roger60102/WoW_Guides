# 12.1(S2)M+: 瑟沙利斯神廟
![templeofsethraliss](/images/templeofsethraliss.jpg)

- 8.0的五人本，位於庫爾提拉斯-沃魯敦(座標: 51.9, 26.7)。
- 一王後的有段刷新大量地板技的路，命中秒殺傷害。
- 三王後小小怪無進度，並且需為2個瑟沙利斯之眼充能才能解鎖通往尾王的路。

## 一號首領: 阿德利斯和艾斯匹
阿德利斯(黃)與艾斯匹(白)會輪流獲得**風暴祝福**免疫所有傷害。
阿德利斯施放雷系技能，艾斯匹施放風系技能。

- 艾斯匹會點1人**狂風**，造成傷害附帶dot，注意減傷。
- 艾斯匹施放**烈風之力**，鎖定全員位置直線型地板，造成傷害附帶擊退。
- 阿德利斯會點1人**雷霆與閃電**套藍圈，數秒後造成範圍內aoe，需集中分攤，結束後原地刷新地板技。
- 艾斯匹會點2人**狂暴之風**套白圈，數秒後留下髒水，觸碰造成4秒沉默並繳械，需出人群至場邊放水。
- 阿德利斯施放**過載**，8秒內提升100%攻速，並且近戰攻擊附帶25%自然傷害，坦克注意減傷。

## 二號首領: 莫芮克莎
**雷霆噴吐**點2人位置持續刷新地板技並留下髒水。
**毒蛇風暴**造成全場aoe附帶擊退，同時刷新大量地板技。
滿能量施放**孵化**刷新數個小怪，接著**鑽地**移動。

- 打坦技**閃電噬咬**，高額傷害附帶7秒dot，坦克注意減傷。
- 召喚**蛇群**昏迷2人，期間會有dot，可透過其他人給控直接解除或打掉蛇群。
- 被點**雷霆噴吐**無需刻意往場外，只需移動放水。
**毒蛇風暴**時注意減傷。
- 莫芮克莎**鑽地**後的黃圈代表其位置，會繞圈移動並隨機衝鋒，命中造成高額傷害附帶擊飛。
**孵化**小怪中的大蛇會原地刷新地板技，小蛇會點1人造成直傷，多給控場盡速擊殺。

## 三號首領: 加瓦茲特
召喚3個**閃電尖塔**持續為加瓦茲特充能，若滿能量會施放**消耗充能**，造成全場高額aoe並施加20秒減少50%玩家造成的傷害，同時自身增傷25%。
加瓦茲特的能量會自動衰減。

- 刷新**閃電尖塔**後需擋線，期間會有dot並且物理易傷250%，即建議坦克外玩家擋，坦克亦需適當帶位以便其他人擋線。
- 擋線結束後施放**感應**，造成全場aoe並留下髒水，注意減傷並帶位。

## 四號首領: 瑟沙利斯化身
將瑟沙利斯化身生命值治療滿即完成此首領戰，場上存在精華褻瀆者時無法直接治療化身，而腐化的守護者與扭曲妖術師會妨礙玩家擊殺精華褻瀆者。當精華褻瀆者擊殺完，會刷新數波無信折磨者，妨礙治療為化身補血。

- 腐化的守護者的打坦技**腐化打擊**，高額傷害並施加dot，坦克注意減傷。
- 腐化的守護者會點1人**暗邪衝鋒**施加dot。
瀕臨死亡時會原地刷新地板技，之後範圍內出現3個**腐化生命力**，需3個DPS接圈為化身施加hot，否則全場超高額aoe並施加易傷。
接圈後會施加15秒dot，期間降低33%造成的治療與物理易傷300%。
- 每個無信折磨者死亡可為化身恢復0.7%生命值，若轉火夠快就能刷新愈多波。
- 扭曲妖術師的**烈焰震擊**必斷，被套圈注意減傷並到場邊放水。
