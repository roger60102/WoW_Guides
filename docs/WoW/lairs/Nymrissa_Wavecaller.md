# 12.1巢穴首領: 妮莉莎．喚浪者
![nymrissawavecaller](/images/nymrissawavecaller.jpg)
最後編輯時間: 2026/08/24

## 簡介
巢穴為12.1新增，像探究一樣能在入口選擇難度，提供世界、普通、英雄與傳奇四種難度。
當選擇世界難度時就和以往的世界首領一樣，而若是自行組隊挑戰則是三種難度擇一，門外也有副本集合石。

傳奇難度與普通、英雄同樣，接受15-25人挑戰並彈性調整難度與獎勵。

巢穴浪縛岩窟，位於**盤蛇島(座標: 59.9, 66.3)**
的水下。
![thetideboundgrotto](/images/thetideboundgrotto.jpg)

每輪開始王會在場中央刷新大泡泡，泡泡存在時場邊水域會週期召喚數個小怪，小怪無仇恨並且只會朝泡泡移動，碰到泡泡就會強化。
施放幾次常規技能後，會刷新數個波浪包圍場地，湧向場中央引爆泡泡，結束一輪技能。

## 指南
### 普通難度
- 小怪吃控場，需優先轉火避免小怪碰到泡泡，若不幸出現強化小怪仍需優先擊殺。
- 打坦技每次疊加易傷，視情況換坦。
- 治療注意每輪王會對全員施加dot，以及泡泡爆炸時會有全場aoe。
- 包圍場地的波浪會有缺口，可提前移動避免命中。
- 王會點名數個玩家頭頂白箭頭，被點名移動到場邊，數秒後原地刷新冰球，觸碰會施加dot並汙染地板。
- 戰鬥時間達7:50滿能量後狂暴，施放滅團技。

### 英雄難度
- 王每輪對全員施加dot時，會疊加buff提升5%冰霜傷害，為軟狂暴機制。
- 冰球會自動爆炸造成全場高額aoe與dot，需主動提前撞掉冰球，由於觸碰冰球會施加dot與冰霜易傷，並且效果可堆疊，因此每人別一次撞太多。

### 傳奇難度
- 召喚的小怪中會有為周圍盟友99%減傷的特殊怪，需優先擊殺。
- 由於撞掉冰球時會造成全場aoe，因此需分配錯開時間觸碰，並且撞掉冰球後，被汙染的地板不再隨時間自動消失。
- 打坦技從多段傷害變為持續水柱，坦克會一直被推開，需利用此技能清除場地髒水。

## 技能
- **引誘泡泡**: 場中央的大泡泡。
    - **泡鰭奔岸者**  
    周圍水域召喚的小怪。
    ::: details 傳奇難度
    - **泡鰭霜鱗者**  
    召喚小怪中的特殊怪。  
        - **冰霧護盾**: 為周圍盟友提供99%減傷。
    ::: 
    - **泡鰭狂戰士**  
    觸碰到泡泡後被強化的小怪。  
        - **脈動浪潮**: 持續造成全場aoe。
    - **砰!**: 泡泡引爆時造成全場aoe附帶擊退。
- **湧動渦流**: 包圍場地並引爆泡泡的波浪，命中造成致命傷害。
- **刺骨冰霜**: 點數名玩家頭頂白箭頭，施加dot與降低移速，數秒後原地刷新**冰霜之球**。
    - **冰霜之球**: 觸碰造成傷害並施加dot，同時原地刷新**滯留冰霜**。
    - **滯留冰霜**: 範圍內每秒造成傷害，並且會滑動。
    ::: details 英雄難度
    觸碰**冰霜之球**的效果可堆疊。

    - **粉碎**: **刺骨冰霜**刷新的**冰霜之球**會在數秒後爆炸，造成全場高額aoe與dot，此效果可堆疊。
    ::: 
    ::: details 傳奇難度
    - **冰霜爆發**: 觸碰**冰霜之球**時造成全場aoe。
    ::: 
- **冰刃亂舞**: 對當前目標造成多段傷害並疊加該技能易傷。
::: details 傳奇難度
**水流噴射**替代**冰刃亂舞**。

- **水流噴射**: 對當前目標持續造成傷害與推開，並疊加debuff，期間該技能易傷，該技能可清除目標周圍的**滯留冰霜**。
::: 
- **深淵之雨**: 先對全員施加短時間dot後，額外施加長時間dot。
    ::: details 英雄難度
    - **喚浪者之力**: 每次施放**深淵之雨**後疊加，提升造成的冰霜傷害。
    ::: 
- **無盡浪潮**: 戰鬥時間過長的狂暴滅團技，持續造成全場高額aoe。
