# 12.1巢穴首領: 妮莉莎．喚浪者
![nymrissawavecaller](/images/nymrissawavecaller.jpg)

## 簡介
巢穴為12.1新增，像探究一樣能在入口選擇難度，提供世界、普通、英雄與傳奇四種難度。
當選擇世界難度時就和以往的世界首領一樣，而若是自行組隊挑戰則是三種難度擇一，門外也有副本集合石。

共兩個階段，第一階段需擊殺不斷出現的小怪，世界難度於此階段時會讓玩家陸續加入。
第二階段首領現身後會依據5-40人彈性調整難度。
傳奇難度與普通、英雄同樣，接受15-25人挑戰。

巢穴浪縛岩窟，位於**盤蛇島(座標: 59.9, 66.3)**
的水下。
![thetideboundgrotto](/images/thetideboundgrotto.jpg)

### 重要機制
- 場上刷新的數個**漂浮冰球**需在自動爆炸前主動觸碰，由於會造成全場aoe，建議安排分隊錯開時間觸碰。
- 小怪受控制效果影響，需在其走到場中央的**誘人的泡泡**前擊殺，以免進入後獲得強化。
- 妮莉莎會在進入戰鬥6分鐘後狂暴，施放**無盡潮汐**造成持續性超高額aoe。
